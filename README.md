# Basketball Player Toolkit

An independent, open-source Python toolkit for descriptive basketball statistics.

Features: CSV input, player-level totals, per-game averages, shooting percentages and approximate true shooting percentage. No proprietary marketplace, scouting or ranking logic.

## Quick start

Requires Python 3.9+.

```bash
python -m basketball_toolkit examples/games.csv
python -m unittest discover -s tests -v
```

## Status

Early-stage MVP, version 0.1.0. Contributions and bug reports welcome. No claims of adoption or production readiness.
